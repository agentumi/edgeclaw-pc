# EdgeClaw UI 통합 설계도 V2.1 (확장메뉴 포함)

버전: 2.1  
작성일: 2026-03-15  
목표: 기존 메뉴/기능 유지 + 확장메뉴 추가 + SPA 통합 안정화

---

## 1. 목표 및 범위

- 기존 메뉴와 기능을 모두 유지한다.
- 단일 SPA 구조로 통합하여 화면 분리 문제를 제거한다.
- 확장메뉴(Extensions)를 추가하고 확장 기능을 설계한다.

---

## 2. 유지해야 할 기존 메뉴/기능

- Mission Control: 미션 진행, 시스템 상태, 히스토리
- Agents: 생성, 임포트, 배포, 그래프
- Memory: 그래프, 검색, 문서
- Automations: 템플릿 목록, 실행, 상태 모니터링
- Marketplace: 탐색, 설치, 업데이트
- Settings: 계정/권한, 보안, 알림

---

## 3. 확장메뉴(Extensions) 설계

### 3.1 확장메뉴 목적
- 회사 운영을 완전자동화하기 위한 모듈형 확장 기능 제공.
- 비즈니스/개발/마케팅/투자 워크플로우를 공통 플랫폼에서 관리.

### 3.2 확장메뉴 구성
- Notes: 회의/리서치 노트 수집 및 Memory 자동 동기화
- Compute: 워크로드 스케줄링 및 리소스 최적화
- Security: RBAC 점검, 정책 검증, 이상행동 탐지
- Network: 연결 품질 모니터링 및 자동 복구
- Economy: 비용 최적화, 예산 경보, 투자 지표 분석

### 3.3 확장 기능 공통 스키마
- 입력: 데이터 소스, 일정, 목표 지표
- 실행: 워크플로우 단계, 에이전트 할당
- 출력: 리포트, 알림, 대시보드 카드

---

## 4. 통합 아키텍처

### 4.1 SPA 구조
- 하나의 HTML에 모든 뷰를 포함한다.
- `view-*` 섹션 전환으로 화면 이동을 처리한다.
- 해시 라우팅으로 새로고침 시 현재 뷰를 유지한다.

### 4.2 공통 레이아웃
- Sidebar: 메뉴 + 확장메뉴 + 디바이스 상태
- Header: 검색, 상태 칩, 현재 뷰 표시
- Context Panel: 로그/메모리/미션 상태

### 4.3 전역 상태(AppState)
- 미션, 에이전트, 메모리, 자동화 상태를 통합 저장.
- 메뉴 이동 시 상태를 유지한다.

---

## 5. 메뉴별 PRD (핵심 기능)

### 5.1 Mission Control
- 현재 미션 상태, 진행률, ETA 표시
- 단계별 로그 및 결과 접근
- 인프라 지표(CPU/RAM/컨테이너) 요약

### 5.2 Agents
- 에이전트 생성/임포트/배포
- 관계 그래프와 작업 단계 모니터링
- 미션 단계와 에이전트 연결

### 5.3 Memory
- 그래프 기반 탐색
- 최근 기록, 문서 뷰
- 미션/자동화 결과와 양방향 연결

### 5.4 Automations
- 템플릿 기반 워크플로우 생성
- 실행 상태 모니터링
- 결과물 자동 아카이빙 및 리포트 생성

### 5.5 Marketplace
- 템플릿/플러그인 설치
- 업데이트 관리
- 설치 즉시 Automations에 반영

### 5.6 Settings
- 역할 기반 접근 제어
- 보안 정책 및 감사 로그
- 알림 채널 설정

### 5.7 Extensions
- 확장 모듈 검색/필터/실행 상태 모니터링
- 모듈별 정책 승인 및 상태 점검
- 결과물을 Mission/Memory/Automations에 자동 연결

---

## 6. UI/UX 통합 규칙

- 공통 디자인 토큰을 단일 CSS로 관리한다.
- Sidebar/Topbar는 모든 뷰에서 동일한 위치와 형태를 유지한다.
- 확장메뉴는 기존 메뉴와 동일한 상호작용 규칙을 따른다.

---

## 7. 우선순위별 체크리스트

### P0
- 단일 HTML 구조로 통합
- 모든 라우트가 동일 HTML을 반환
- 공통 레이아웃과 디자인 토큰 통합
- 메뉴 클릭 시 뷰 전환 정상 동작
- 확장메뉴 뷰 전환 및 필터 동작 확인

### P1
- 전역 상태(AppState) 도입
- 확장메뉴 실행 결과 자동 연결
- Marketplace 설치 즉시 반영

### P2
- 딥링크 지원
- 사용자 맞춤 대시보드
- 확장메뉴 성과 리포트 자동 생성

---

## 8. 완료 기준(DoD)

- 모든 메뉴가 단일 화면에서 전환된다.
- 기능별 상태가 메뉴 이동 후에도 유지된다.
- 확장메뉴 모듈이 Mission/Memory/Automations에 연동된다.
- UI 일관성과 디자인 토큰이 전체에 적용된다.
